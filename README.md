# 불의 마탑 · Torch Prototype

브라우저에서 `index.html`을 열어 테스트할 수 있는 첫 번째 제작 프로토타입입니다.

## 포함 기능

- 타이틀 화면
- 양피지 기반 Torch 제작 화면
- 물방울 모양 기준 마법진
- 마우스·터치 드래그 입력
- 5초 제작 제한
- 선의 정확도와 제작 속도 기반 품질 판정
- 실패 / 일반 / 우수 / 걸작 등급
- 품질별 골드 지급
- 다시 그리기 및 작업 취소

## 테스트 방법

1. `index.html`을 브라우저에서 엽니다.
2. `마탑에 입장하기`를 누릅니다.
3. 회색 물방울 선을 꼭짓점부터 따라 그립니다.
4. 5초 안에 다시 꼭짓점으로 돌아옵니다.
5. 결과 품질과 골드 보상을 확인합니다.

외부 라이브러리나 별도 서버가 필요하지 않습니다.
